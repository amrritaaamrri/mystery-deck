# Arcana Match — Build Notes

- The project is a WebDev static React 19 application under `/home/ubuntu/tarot-match`.
- User requirement: a memory matching game with face-down cards, two-card turns, clear-board goal, fewest moves goal, gilded ornate tarot style, softly shimmering flips, and velvet tabletop context.
- The chosen direction is **The Gilded Reliquary**: late Art Nouveau bookbinding, deep oxblood velvet, Reliquary Gold (#C9A45B), parchment ivory, and restrained ambient motion.
- Generated images are referenced via persistent `/manus-storage/...` URLs and are not stored in the project tree.
- The game uses React for accessible cards and HUD state, CSS for tactile flips and foil shimmers, and Babylon.js for the lifecycle-safe animated velvet background beneath the reading table.
